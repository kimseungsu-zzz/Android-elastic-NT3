# Changelog

All notable changes to Elastic (NT3) are documented in this file.

## Unreleased

- Updated project documentation, attribution, privacy information, issue
  templates, and platform metadata for the NT3 fork.

## 1.0.0 - 2026-08-28

- Added a NetworkTables 3 TCP client using port 1735.
- Added NT3 protocol and type tests.
- Limited network topic types to those supported by the NT3 wire protocol.
- Removed the newer NetworkTables transport and struct-topic implementation.
- Removed ElasticLib integration and robot-hosted layout controls.
- Removed SystemCore and alternate-distribution packaging.
- Renamed the displayed application to Elastic (NT3).
- Added desktop CI builds for Windows, macOS, and Linux.
